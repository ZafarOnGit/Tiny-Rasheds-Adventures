### 🎮 TINY RASHED — Pre-Alpha 1.0 (Build Submission)

This build is officially uploaded and submitted for Madar Games: Tolerance and Status Won. This package contains the fully compiled, playable standalone executable for TINY RASHED Pre-Alpha 1.0. Optimized utilizing the D3D12 graphics API and built on the Unity engine, this build represents the foundational mechanics, core gameplay loops, and initial asset framework designed for the event evaluation.

### 📦 What’s Included in This Build:

TINY RASHED PRE ALPHA 1.0.exe: The primary desktop application executable. Engine & Graphics Architecture: Complete runtime support environments via UnityPlayer.dll and explicit D3D12 file routing for stable DirectX 12 rendering performance.Data & Debug Infrastructure: The integrated _Data asset directory alongside BurstDebug telemetry frameworks to track structural stability during active test sessions.

### ⚠️ Technical Setup Notes:

To ensure the game executes correctly, please extract the entirety of the compressed archive into a unified directory before launching. Moving or modifying individual files (such as dstorage.dll or the data folders) outside of this root path will break internal dependencies and prevent the application from initializing.
